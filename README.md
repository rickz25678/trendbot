# Trend Bot
Every hour: reads X trending, Google Trends, Google News, Know Your Meme, Bluesky and Wikipedia,
uses Gemini to keep only viral characters/animals/objects that could work as a meme coin,
checks if the ticker is OPEN / TAKEN on Solana, Robinhood Chain and Elysium,
adds trending chain coins + crypto news, and sends it to Telegram.
Secrets: GEMINI_API_KEY, TELEGRAM_TOKEN, TELEGRAM_CHAT_ID.
